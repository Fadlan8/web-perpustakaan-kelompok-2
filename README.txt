RUANGBACA — PROYEK VISUAL STUDIO CODE
=====================================

ISI FOLDER
- index.html       : struktur halaman website
- css/style.css    : desain, warna, ukuran, dan tata letak
- js/script.js     : pencarian, kategori, detail buku, dan interaksi
- images/          : gambar sampul anime
- README.txt       : panduan ini

CARA MENJALANKAN DI VISUAL STUDIO CODE
1. Ekstrak file RuangBaca_VSCode.zip.
2. Buka aplikasi Visual Studio Code.
3. Pilih File > Open Folder.
4. Pilih folder RuangBaca_VSCode hasil ekstrak.
5. Buka menu Extensions (ikon kotak-kotak di sisi kiri).
6. Cari ekstensi "Live Server" dari Ritwick Dey, lalu klik Install.
7. Klik kanan file index.html.
8. Pilih "Open with Live Server".
9. Website akan terbuka di browser.

CARA MENGEDIT
- Konten dan struktur halaman: edit index.html.
- Desain dan warna: edit css/style.css.
- Data buku dan fungsi interaktif: edit js/script.js.
- Sampul buku: ganti gambar di folder images. Jika mengganti nama file,
  sesuaikan juga daftar coverImages di js/script.js.

CATATAN
Fitur login/daftar dan tombol Google pada versi ini masih berupa demo tampilan.
Belum ada server, database, atau autentikasi sungguhan.
